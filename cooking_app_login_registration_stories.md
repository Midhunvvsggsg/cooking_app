As a user, I want to register a new account using my username, email, and password, log in using my email and password, receive clear error messages if my input is invalid or my login fails, and have my account information stored locally so that I can securely access my account and continue using the application across sessions.

Acceptance Criteria
User can create an account by entering a username, email, and password.
User can log in using their registered email and password.
Appropriate error messages are displayed for empty fields or invalid credentials.
User data is stored in local storage and persists after the application is closed and reopened.
