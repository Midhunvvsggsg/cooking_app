# Cooking App User Story

## Login / Registration

User Story 1: Registration

As a user,
I want to register an account using my username, email, and password,

So that
I can create an account.

User Story 2: Login

As a user,
I want to log in using my email and password,

So that
I can access my account.

User Story 3: Error Feedback

As a user,
I want to receive appropriate error messages when registration or login fails,

So that
I know how to correct the issue.


## Home Screen

User Story 4: Recipe Overview

As a user,
I want to view featured recipes, recently viewed recipes, and my favorite recipes on the home screen,

So that
I can quickly access recipes.

User Story 5: New User Guide

As a new user,
I want to see a short introduction to the app's features on the home screen,

So that
I can learn how to search, save, and cook recipes easily.

User Story 6: Quick Access

As a user,
I want to access recipe categories, my saved recipes, and my shopping list directly from the home screen,

So that
I can navigate the app quickly.


## Detail Screen

User Story 7: Recipe Details

As a user,
I want to view detailed information about a selected recipe, including ingredients, cooking instructions, preparation time, and serving size,

So that
I can prepare the recipe correctly.

User Story 8: Save and Share Recipe

As a user,
I want to save recipes to my favorites and share them with others,

So that
I can access them later and recommend them to friends and family.

User Story 9: Related Recipes

As a user,
I want to view similar or related recipes on the recipe detail screen,

So that
I can discover more dishes that match my interests.
