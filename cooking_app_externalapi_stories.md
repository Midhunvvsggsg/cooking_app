User Story 1: Recipe API Integration

As a user,
I want to view the latest recipes fetched from an external recipe API,

So that
I can discover new dishes and cooking ideas.


User Story 2: Nutrition Information

As a user,
I want to view nutritional information for recipes using an external nutrition API,

So that
I can make healthier food choices.


User Story 3: Ingredient Availability

As a user,
I want to search recipes based on the ingredients I have using an external recipe API,

So that
I can find suitable recipes without buying unnecessary ingredients.
