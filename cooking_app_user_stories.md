# Cooking App User Stories

User Story 1: Login and Registration

As a user,
I want to register and log in using my account credentials,

So that
I can securely access the cooking app.


User Story 2: Home Screen

As a user,
I want to view featured recipes and quick access options on the home screen,

So that
I can easily find recipes and navigate the app.


User Story 3: Recipe Details

As a user,
I want to view detailed information about a selected recipe,

So that
I can prepare the recipe correctly.


User Story 4: Persistent Data

As a user,
I want my login session and preferences to be saved,

So that
I do not have to set them up every time I open the app.


User Story 5: External API

As a user,
I want to view recipes fetched from an external recipe API,

So that
I can discover new dishes and cooking ideas.


User Story 6: Settings Menu

As a user,
I want to access the settings menu from any screen,

So that
I can easily manage my app preferences.


User Story 7: Settings Screen

As a user,
I want to enable dark mode and update my account information,

So that
I can personalize and secure my experience.


User Story 8: Notifications

As a user,
I want to receive notifications about new recipes and cooking reminders,

So that
I stay updated and never miss new content.


User Story 9: Favorites

As a user,
I want to save my favorite recipes,

So that
I can quickly access them whenever I want.

As a user,
I want to view similar or related recipes on the recipe detail screen,

So that
I can discover more dishes that match my interests.
