User Story 1: Login Persistence

As a user,
I want my login session to remain active after closing and reopening the app,

So that
I don't have to log in every time I use the application.


User Story 2: Preference Persistence

As a user,
I want the app to remember my preferences, such as my favorite recipes and theme settings,

So that
I can enjoy a personalized experience every time I use the app.


User Story 3: Recipe Activity Persistence

As an admin,
I want user activity, such as saved recipes and recently viewed recipes, to be stored,

So that
I can analyze user engagement and improve the application.
